注意力残差 · 精读页

把固定单位权重的残差累加，换成「沿深度维」的 softmax 注意力。优先读金色名词芯片与每段绿色小结；需要细节再展开原文/译文。

核心：AttnRes 可扩展：Block AttnRes (N≈8) 痛点：PreNorm dilution 载体：Kimi Linear 48B / 1.4T

一眼公式 读正文前先看

标准残差均匀求和 → AttnRes 用 α 加权；α 来自每层伪查询 w_l 对历史层输出做 softmax。

标准残差： hl = hl-1 + fl-1(hl-1) = Σi<l vi

AttnRes： hl = Σi<l αi→l · vi，α = softmax( wlᵀ RMSNorm(k) )

Block： 先把层压成 N 个块表示 bn，再对块做注意力（成本 O(Nd)）。

Abstract 摘要 3 段

小结 · 问题：固定权重残差 → PreNorm dilution；方案：沿深度做 softmax 注意力聚合。
Original
Residual connections with PreNorm are standard in modern LLMs, yet they accumulate all layer outputs with fixed unit weights. This uniform aggregation causes uncontrolled hidden-state growth with depth, progressively diluting each layer's contribution. We propose Attention Residuals (AttnRes), which replaces this fixed accumulation with softmax attention over preceding layer outputs, allowing each layer to selectively aggregate earlier representations with learned, input-dependent weights.
译文
残差连接配合 PreNorm 已成为现代大语言模型的标配，但它们以固定的单位权重累加所有层输出。这种均匀聚合会使隐藏状态幅度随深度失控增长，并逐步稀释每一层的贡献。我们提出注意力残差（Attention Residuals, AttnRes）：用对先前层输出的 softmax 注意力替换固定累加，使每一层能以可学习、依赖输入的权重选择性地聚合更早的表示。

小结 · 可扩展版：块级注意力 + 流水线缓存 + 两阶段计算，接近零成本替换。
Original
To address the memory and communication overhead of attending over all preceding layer outputs for large-scale model training, we introduce Block AttnRes, which partitions layers into blocks and attends over block-level representations, reducing the memory footprint while preserving most of the gains of full AttnRes. Combined with cache-based pipeline communication and a two-phase computation strategy, Block AttnRes becomes a practical drop-in replacement for standard residual connections with minimal overhead.
译文
为应对大规模训练中对所有先前层输出做注意力带来的显存与通信开销，我们提出 Block AttnRes：把层划分成若干块，只在块级表示上做注意力，从而降低显存占用，同时保留 Full AttnRes 的大部分收益。再结合基于缓存的流水线通信与两阶段计算策略，Block AttnRes 可 practically 作为标准残差的即插即用替代，开销很小。

Scaling law experiments confirm that the improvement is consistent across model sizes, and ablations validate the benefit of content-dependent depth-wise selection. We further integrate AttnRes into the Kimi Linear architecture (48B total / 3B activated parameters) and pre-train on 1.4T tokens, where AttnRes mitigates PreNorm dilution, yielding more uniform output magnitudes and gradient distribution across depth, and improves downstream performance across all evaluated tasks.
译文
缩放律实验表明收益在不同模型规模上一致；消融验证了「内容依赖的深度维选择」确实有用。我们进一步把 AttnRes 接入 Kimi Linear（总参 48B / 激活 3B），在 1.4T token 上预训练：AttnRes 缓解 PreNorm dilution，使各层输出幅度与梯度分布更均匀，并在所有评测任务上提升下游表现。

1 Introduction 引言 7 段

小结 · 残差不只是梯度通路，还决定「深度方向上信息如何聚合」。
Original
Standard residual connections are the de facto building block of modern LLMs. The update h_l = h_{l-1} + f_{l-1}(h_{l-1}) is widely understood as a gradient highway that lets gradients bypass transformations via identity mappings, enabling stable training at depth. Yet residuals also play a second role that has received less attention.
译文
标准残差连接是现代 LLM 事实上的基本构件。更新式 h_l = h_{l-1} + f_{l-1}(h_{l-1}) 通常被理解为「梯度高速公路」：梯度可经由恒等映射绕过变换，从而在深度网络中稳定训练。但残差还有第二个较少被强调的角色。
residual connectiongradient highway
小结 · 序列维已可学习路由，深度维仍是死板的单位权重累加。
Original
Unrolling the recurrence shows that every layer receives the same uniformly-weighted sum of all prior layer outputs; residuals define how information aggregates across depth. Unlike sequence mixing and expert routing, which now employ learnable input-dependent weighting, this depth-wise aggregation remains governed by fixed unit weights, with no mechanism to selectively emphasize or suppress individual layer contributions.
译文
展开递推可见：每一层收到的都是对所有先前层输出的同权求和；残差其实定义了信息如何沿深度聚合。序列混合与专家路由已普遍采用可学习、依赖输入的加权，但深度维聚合仍被固定单位权重统治，无法选择性地强调或抑制某一层的贡献。
depth-wise aggregation
小结 · PreNorm dilution + 不可选择性取回；类比：深度维需要类似「注意力」的解。
Original
In practice, PreNorm has become the dominant paradigm, yet its unweighted accumulation causes hidden-state magnitudes to grow as O(L) with depth, progressively diluting each layer's relative contribution. Early-layer information is buried and cannot be selectively retrieved; empirically, a significant fraction of layers can be pruned with minimal loss. Recent efforts such as scaled residual paths and multi-stream recurrences remain bound to the additive recurrence, while methods that do introduce cross-layer access are difficult to scale. The situation parallels the challenges that RNNs faced over the sequence dimension before attention provided an alternative.
译文
实践中 PreNorm 已成主流，但无权重累加使隐藏状态幅度随深度按 O(L) 增长，逐步稀释每层相对贡献。早期层信息被埋没且无法选择性取回；经验上大量层可被剪掉而损失很小。缩放残差路径、多流递推等方法仍困在加性递推里；真正引入跨层访问的方法又难以扩展。这正像注意力出现之前，RNN 在序列维上面对的困境。
PreNorm dilutioncross-layer access
小结 · 核心公式：深度维 softmax 注意力；每层仅一个伪查询 w_l。
Original
We observe a formal duality between depth-wise accumulation and the sequential recurrence in RNNs. Building on this duality, we propose Attention Residuals (AttnRes), which replaces the fixed accumulation h_l = Σ_i v_i with h_l = Σ_i α_{i→l} · v_i, where α_{i→l} are softmax attention weights computed from a single learned pseudo-query w_l ∈ R^d per layer. This lightweight mechanism enables selective, content-aware retrieval across depth with only one d-dimensional vector per layer.
译文
我们观察到：深度维累加与 RNN 的序列递推存在形式对偶。据此提出 AttnRes：把固定累加 h_l = Σ_i v_i 换成 h_l = Σ_i α_{i→l} · v_i，其中 α_{i→l} 由每层一个可学习伪查询向量 w_l ∈ R^d 经 softmax 得到。机制很轻：每层只需一个 d 维向量，即可实现沿深度的选择性、内容感知检索。

Original
Indeed, standard residual connections and prior recurrence-based variants can all be shown to perform depth-wise linear attention; AttnRes generalizes them to depth-wise softmax attention, completing for depth the same linear-to-softmax transition that proved transformative over sequences.
译文
事实上，标准残差与既有基于递推的变体都可以看成深度维线性注意力；AttnRes 把它们推广到深度维 softmax 注意力——完成了序列维上曾经「线性→softmax」那次关键性跃迁在深度维上的对应。

小结 · Full 小规模免费；大规模用 Block，成本 O(Nd)。
Original
In standard training, Full AttnRes adds negligible overhead, since the layer outputs it requires are already retained for backpropagation. At scale, however, activation recomputation and pipeline parallelism are routinely employed, and these activations must now be explicitly preserved and communicated across pipeline stages. We introduce Block AttnRes to maintain efficiency in this regime: layers are partitioned into N blocks, each reduced to a single representation via standard residuals, with cross-block attention applied only over the N block-level summaries. This brings both memory and communication down to O(Nd).
译文
普通训练中，Full AttnRes 几乎无额外开销，因为反传本来就要保留层输出。但大规模场景常用激活重计算与流水线并行，这些激活就必须被显式保留并跨 stage 通信。为此提出 Block AttnRes：把层划成 N 个块，块内用标准残差压成一个表示，块间只对 N 个块级摘要做注意力，使显存与通信降到 O(Nd)。

2 Motivation 动机 4 段

小结 · 关键：本文的「层」= Attention 或 MLP，不是整个 Transformer block。
Original
Notation. Consider inputs of shape B×T×d. For a single token, h_l ∈ R^d is the hidden state entering layer l (l=1…L); the token embedding is h_1. f_l is the transformation of layer l; in Transformers we treat each self-attention or MLP as an individual layer.
译文
记号：输入形状 B×T×d。对单 token，h_l ∈ R^d 是进入第 l 层的隐藏状态（l=1…L）；词嵌入为 h_1。f_l 是第 l 层变换；在 Transformer 中把每个 self-attention 或 MLP 都当成单独一层。
layer
小结 · 经典残差 = 恒等捷径 + 均匀求和。
Original
Residual Learning. Residuals allow gradients to bypass transformations: h_l = h_{l-1} + f_{l-1}(h_{l-1}). Expanding gives h_l = h_1 + Σ_{i=1}^{l-1} f_i(h_i). The key insight is identity mapping: a direct path for information and gradients. In backprop, ∂L/∂h_l expands to a product that always preserves an identity term, providing a depth-independent gradient highway.
译文
残差学习：h_l = h_{l-1} + f_{l-1}(h_{l-1})，展开即嵌入加所有先前层输出之和。关键是恒等映射，反传展开式中恒保留 I 项，形成与深度无关的梯度通路。
identity mapping
小结 · Highway 可学门控，但仍是「只看上一状态」的递推。
Original
Generalizing Residuals. Fixed unit coefficients treat every layer uniformly. Highway networks introduce learned element-wise gates: h_l = (1−g_l)⊙h_{l-1} + g_l⊙f_{l-1}(h_{l-1}). More generally both are weighted recurrences h_l = α_l·h_{l-1} + β_l·f_{l-1}(h_{l-1}), with residual α=β=1 and Highway α=1−g, β=g.
译文
推广残差：固定单位系数无法适应深度混合。Highway 引入逐元素门控：在变换与恒等路径间插值。二者都是加权递推 h_l = α_l·h_{l-1} + β_l·f(...)，残差取 α=β=1，Highway 取 α=1−g、β=g。
Highway networks
小结 · 三大痛点：不能选、不能恢复、深层输出膨胀。
Original
Limitations. Whether fixed or gated, each layer only accesses its immediate input h_{l-1}—a single compressed state conflating all earlier outputs. This implies: (1) no selective access—attention vs MLP get the same aggregate; (2) irreversible loss—once aggregated, information cannot be selectively recovered; (3) output growth—later layers learn larger outputs to stay influential, risking instability. These motivate selective aggregation over all preceding layers.
译文
局限：无论固定还是门控，每层只能访问紧邻输入 h_{l-1}——一个混杂了全部历史的压缩状态。后果：(1) 无法选择性访问；(2) 聚合损失不可逆；(3) 深层为争影响力输出越来越大，训练不稳。因此需要能对所有先前层做选择性聚合的机制。
selective access

3 Attention Residuals 方法 4 段

小结 · 把「序列注意力」搬到「层间/深度维」。
Original
The Duality of Time and Depth. Like RNNs over time, residuals compress all prior information into a single state h_l over depth. Transformers improved RNNs by replacing recurrence with attention. We propose the same for depth: h_l = α_{0→l}·h_1 + Σ_{i=1}^{l-1} α_{i→l}·f_i(h_i), with Σ α = 1. Depth L is typically < 1000, so O(L²) depth attention is feasible. We call this Attention Residuals (AttnRes).
译文
时间—深度对偶：残差像 RNN 一样把历史压进单一状态。Transformer 用注意力取代了序列递推；我们对深度做同样的事：用归一化权重对嵌入与各层输出加权求和。深度通常不大（L<1000），O(L²) 可接受。此即 AttnRes。
sequence-depth dualityAttnRes
小结 · 公式要点：伪查询 + RMSNorm(k) + softmax；键值=历史层输出。
Original
Full Attention Residuals. Weights α_{i→l} = ϕ(q_l, k_i) / Σ_j ϕ(q_l, k_j) with ϕ(q,k)=exp(qᵀ RMSNorm(k)). For each layer: q_l = w_l (learned), and for sources: k_i = v_i = h_1 (i=0) or f_i(h_i) (i≥1). Then h_l = Σ α_{i→l} v_i. RMSNorm inside ϕ stops large-magnitude layers from dominating softmax. Cost: O(L²d) arithmetic, O(Ld) memory per token—modest because depth ≪ sequence length.
译文
Full AttnRes：α 为带 RMSNorm 的 softmax。查询 q_l 是每层可学习向量 w_l；键/值来自嵌入或各层输出。RMSNorm 防止大幅度层垄断注意力。每 token 算术 O(L²d)、显存 O(Ld)，因深度远小于序列长度，可接受。
Full AttnRespseudo-queryRMSNorm
小结 · 小规模几乎免费；大规模通信成瓶颈。
Original
Overhead. O(Ld) memory overlaps activations already kept for backprop in vanilla training—no extra memory. At scale with recomputation and pipeline parallelism, those outputs must stay alive and cross stages, so memory and communication grow as O(Ld).
译文
开销：普通训练中 O(Ld) 与反传激活重合，无额外显存；大规模重计算/流水线下必须跨 stage 保活并传输，于是显存与通信都变成 O(Ld)。
activation recomputation
小结 · w_l 解耦 → 可批处理；通信仍需减源数量（L→N）。
Original
A deliberate design choice: the pseudo-query w_l is a learned parameter decoupled from the layer's forward computation. Thus attention weights for a group of layers can be computed in parallel without waiting for sequential outputs—enabling block batching. But under pipeline parallelism, O(Ld) cross-stage communication cannot be fixed by local batching alone, motivating Block AttnRes.
译文
刻意设计：伪查询 w_l 与前向计算解耦，故一组层的注意力可并行算，便于块内批处理。但流水线跨 stage 的 O(Ld) 通信无法仅靠本地批处理消除，因而需要 Block AttnRes。
pseudo-query

3.2 Block AttnRes 块注意力残差 3 段

小结 · 块内求和压缩，块间注意力；N≈8 往往够用。
Original
Block AttnRes partitions L layers into N blocks. Within a block, outputs are reduced to one representation by summation; across blocks, full attention runs over only N block-level representations plus the embedding. Memory and communication fall from O(Ld) to O(Nd).
译文
Block AttnRes 把 L 层分成 N 块：块内用求和压成一个表示；块间只对 N 个块表示（外加嵌入）做全注意力。显存/通信从 O(Ld) 降到 O(Nd)。
Block AttnRes
小结 · 值矩阵随「是否块首层」切换：历史块 ± 当前部分和。
Original
Intra-block: for block n with layers B_n, b_n = Σ_{j∈B_n} f_j(h_j); partial sums b_n^{(i)} cover the first i layers in the block. Inter-block: the first layer of a block attends to [b_0,…,b_{n-1}]; subsequent layers also attend to the current partial sum b_n^{(i-1)}. b_0 = h_1 always.
译文
块内：b_n 为块内层输出之和，并维护部分和。块间：块内第一层看历史块表示；后续层额外看当前块部分和。嵌入始终作为 b_0。
partial sum
小结 · 工程甜点：大约 8 个块。
Original
Efficiency. Attending over N instead of L reduces memory O(L)→O(N) and compute O(L²)→O(N²). N interpolates extremes: N=L recovers Full AttnRes; N=1 reduces to standard residuals with embedding isolated as b_0. Empirically N≈8 recovers most benefits across scales.
译文
效率：源数量 L→N。N=L 回到 Full；N=1 近似标准残差（嵌入单独为 b_0）。经验上 N≈8 即可拿回大部分收益。
Block AttnRes

4 Infrastructure 系统实现 3 段

小结 · 关键优化：缓存历史块，只传增量。
Original
Training / Pipeline communication. Naïvely sending the full block history at every pipeline transition incurs quadratic communication in the number of chunks. Cross-stage caching keeps previously received blocks in local memory so later virtual stages only transmit incremental blocks—reducing peak per-transition cost by about V× and enabling overlap with 1F1B steady state. Measured end-to-end training overhead under pipeline parallelism is < 4%.
译文
训练/流水线：朴素地每次传输完整块历史会导致通信随 chunk 数二次增长。跨 stage 缓存让后续 virtual stage 只传增量块，峰值成本约降 V 倍，并可与 1F1B 稳态重叠。测得端到端训练开销 < 4%。
cross-stage cachingpipeline parallelism
小结 · 批处理块间 + 顺序块内 + online softmax 合并 = 又对又快。
Original
Inference / Two-phase strategy. Phase 1 batches all S queries in a block against cached block K/V once, returning outputs and softmax stats (max, LSE). Phase 2 sequentially attends to evolving intra-block partial sums and merges with Phase 1 via online softmax—exactly equivalent, I/O friendly, and fusable. End-to-end inference latency overhead < 2% on typical workloads.
译文
推理/两阶段：Phase 1 把块内全部伪查询一次性对历史块 K/V 批处理；Phase 2 再对块内演化部分和顺序计算，并用 online softmax 与 Phase 1 精确合并。I/O 友好、可融合；典型推理延迟开销 < 2%。
two-phase computationonline softmax
小结 · 长上下文靠 TP 分片 + chunked prefill。
Original
Memory-efficient prefilling. Caching N·T·d block states for long context is costly (e.g. ~15GB at 128K with 8 blocks). Sharding along sequence across TP devices plus chunked prefill drops per-device overhead dramatically (example: to ~1.9GB, further <0.3GB with 16K chunks).
译文
预填充省显存：长上下文缓存块状态很贵。沿序列维做张量并行分片，再配合分块 prefill，可大幅降低每卡占用。

5.4–6 分析与理论 3 段

小结 · 可视化：既保留残差局部性，又学会深度跳连。
Original
Learned patterns. Layers attend most to immediate predecessors (locality), yet learn skip connections (off-diagonal). Embedding keeps nontrivial weight, especially pre-attention. Pre-MLP is sharper/local; pre-attention has broader receptive field. Block AttnRes preserves these structures with sharper weights—block compression acts like regularization.
译文
学到的模式：主对角局部性仍在，但出现跨层捷径；嵌入权重持续存在；Attention 前更宽、MLP 前更局部。Block 版保留结构且权重更果断，块压缩类似正则。
attention sink
小结 · 理论主线：把「Transformer 对 RNN 做的事」对残差再做一遍。
Original
Sequence–Depth Duality. Residuals over depth mirror RNNs over time; TTT/fast weights cast sequence recurrence as online learning, reducing to linear attention when linear. Data-dependent gates ↔ Highway; delta rule ↔ DDL; etc. AttnRes goes further: replace depth recurrence with direct cross-layer attention, as Transformers replaced temporal recurrence.
译文
序列—深度对偶把多种残差变体与序列侧方法一一对应。AttnRes 更进一步：直接用跨层注意力取代深度递推。

小结 · 一张 M 矩阵看懂所有残差变体的表达力与结构。
Original
Residuals as structured matrices. Define depth mixing matrix M where M_{i→l} weights layer i's output into layer l. Standard residual → all-ones lower-triangular (1-semiseparable). Highway → input-dependent 1-semiseparable. (m)HC → m-semiseparable. Full AttnRes → dense rank-L. Block → rank between N and N+S. Prior residuals ≈ depth-wise linear attention; AttnRes ≈ depth-wise softmax attention.
译文
深度混合矩阵 M 统一视角：标准残差/Highway/(m)HC/AttnRes 对应不同约束与秩。既往方法≈深度线性注意力；AttnRes≈深度 softmax 注意力。

7 Related Work & Conclusion 相关工作与结论 2 段

小结 · 定位：正交于多流递推，补齐可扩展的深度维 softmax 选择。
Original
Related themes: (1) Norm/scaling/depth stability—PreNorm growth vs PostNorm gradient issues; AttnRes avoids both by selective aggregation. (2) Multi-state recurrence—(m)HC, DDL, SiameseNorm widen state but still condition on immediate predecessor; AttnRes is orthogonal. (3) Cross-layer connectivity—DenseFormer/ELMo static mixes; MUDDFormer/MRLA dynamic but different; AttnRes uses softmax + single pseudo-query + block scaling.
译文
相关三条线：归一化与深度稳定性；多状态递推；跨层连接。AttnRes 用 softmax + 单伪查询 + 分块扩展，与多状态方法正交，并补上可扩展跨层选择。

小结 · 可落地的深度维注意力残差；Block≈8 是当前工程甜点。
Original
Conclusion. Inspired by sequence–depth duality, AttnRes replaces fixed residual accumulation with learned depth-wise attention. Full AttnRes is strong but O(Ld) memory is heavy at scale; Block AttnRes with ~8 blocks recovers most gains. 名词重点解释 点击芯片或下方条目

AttnRes

Attention Residuals，注意力残差：用沿深度维的 softmax 注意力替换固定残差累加。

Full AttnRes

对每一个先前层输出分别做注意力；表达力最强，大规模下通信/显存为 O(Ld)。

Block AttnRes

先把层聚成 N 个块，再对块表示做注意力；成本 O(Nd)，N≈8 常可逼近 Full。

PreNorm

先归一化再算子层，再加回残差。提供干净恒等梯度路径，但隐藏状态幅度易随深度增长。

PreNorm dilution

无权重累加使 ||h||~O(L)，每层相对贡献被稀释；深层被迫输出更大才能「出头」。

pseudo-query

伪查询 w_l：每层一个可学习 d 维向量，不依赖当前前向激活，因而可批处理。

RMSNorm

均方根归一化。此处用于键，避免大幅度层/块垄断 softmax。

depth-wise aggregation

沿网络深度（层间）聚合信息，而非沿序列时间步。

sequence-depth duality

序列递推 ↔ 深度残差递推的形式对偶；启发把注意力从时间维搬到深度维。

depth mixing matrix

矩阵 M，M_{i→l} 表示第 l 层对第 i 层输出的混合权重；统一比较各类残差。

semiseparable

半可分结构：刻画递推型混合矩阵的低秩/结构化程度；秩越高表达越灵活。

Highway networks

用门控在恒等路径与变换间插值的残差推广，仍只看上一状态。

gradient highway

残差展开中恒等项提供的、不随深度消失的梯度直达通路。

identity mapping

恒等映射：信息/梯度可原样穿过层。

cross-layer access

层可以直接访问更早层的个体输出，而不是只看压缩后的 h_{l-1}。

pipeline parallelism

把模型按层切到多个设备流水执行；跨 stage 要传输激活。

cross-stage caching

在流水线物理 stage 上缓存已接收块表示，后续只传增量，避免重复通信。

two-phase computation

Phase1 批处理块间注意力；Phase2 顺序块内部分和并用 online softmax 合并。

online softmax

可增量合并两组 softmax 统计量的技巧，保证两阶段结果与一次性计算等价。

activation recomputation

反向时重算前向激活以省显存；与「必须保活层输出给 AttnRes」冲突，故大规模要额外策略。

partial sum

块内前 i 层输出的累计和，供块内后续层作为额外注意力源。

Kimi Linear

Moonshot 的混合线性注意力架构（KDA+MLA，3:1），本文 48B 实验载体。

KDA

Kimi Delta Attention，通道级门控的线性注意力模块。

MLA

Multi-Head Latent Attention，多头潜在注意力（DeepSeek 系）。

mHC

Manifold-Constrained Hyper-Connections：多流残差并约束转移矩阵，深度维线性注意力代表。

DenseFormer

用固定（训练后静态）标量系数混合历史层；消融显示无增益。

Hyper-Connections

维护多条并行残差流并用学习矩阵混合。

MRLA

对历史层做逐元素 sigmoid 门控的跨层方法，更接近线性注意力而非 softmax 检索。

DDL

Deep Delta Learning：深度侧的 delta-rule 状态更新，对偶于序列侧 DeltaNet。

delta rule

先按 key 擦除再写入的关联记忆更新规则。

scaling law

验证 loss 随算力的幂律关系；用来比较方法在不同规模的效率。

Muon

一种用于 LLM 训练的优化器（Moonlight/Kimi 配方中使用）。

attention sink

某些位置/层稳定吸引高注意力质量的现象；深度维也可出现。

prefilling

推理时先处理长提示并缓存状态的阶段；块表示缓存是显存热点。

sliding-window aggregation

只保留最近 W 个层输出的近似；消融弱于可访问远层的 Block/Full。

layer

本文特指单个 Attention 或 MLP，而不是整个 Transformer block。

depth-wise linear attention

用结构化/核特征递推实现的深度混合，对应标准残差、Highway、(m)HC 等。

depth-wise softmax attention

对历史层输出做显式 softmax 检索；即 AttnRes。

selective access

按内容需要强调或抑制某些历史层，而不是均匀加权。
