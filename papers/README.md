# Papers

每篇论文相关材料单独放在一个文件夹，统一建议结构：

```text
papers/<paper-slug>/
  README.md      # 索引
  paper.pdf      # 原文（或保留 arXiv 文件名）
  index.html     # 精读页：原文+翻译+段落小结+名词+重点引用
```
