Big Bird: Transformers for Longer Sequences

浅色逐段精读：严格按论文脉络拆段，段首给中文小结，段内左右对照 Original / 译文。核心记住三件套——全局 g、窗口 w、随机 r——以及「含星形全局结构 ⇒ 万能近似」。

图案：global + window + random 复杂度：O(n) 理论：万能近似 + 图灵完备 工程：块稀疏 长度：~8×

英文尽量贴近原文；PDF 断行/连字处做了可读性规范化。Table / Figure 数字以 paper.pdf 为准。段末小结是学习用导读，不是论文原文。

§17
小结 · 路线一：不硬改注意力，先裁上下文再喂进标准 Transformer。
Original
There have been a number of interesting attempts aimed at alleviating the quadratic dependency of Transformers, which can be broadly categorized into two directions. First line of work embraces the length limitation and develops methods around it. Simplest methods in this category just employ sliding window, but in general most work fits in the following general paradigm: using some other mechanism select a smaller subset of relevant contexts to feed in the transformer and optionally iterate, i.e. call transformer block multiple times with different contexts each time.

2 BIGBIRD Architecture 架构（核心） 16 段

§22
小结 · 设定：输入是 n 个 d 维向量。
Original
In this section, we describe the BIGBIRD model using the generalised attention mechanism that is used in each layer of transformer operating on an input sequence X = (x₁, …, xₙ) ∈ Rⁿˣᵈ.
译文
本节用「广义注意力机制」描述 BIGBIRD：它用于 Transformer 每一层，作用在输入序列 X = (x₁, …, xₙ) ∈ Rⁿˣᵈ 上。
§23
小结 · 关键改写：不是对全体做 QK，只对图上邻居 N(i) 做。
Original
The generalized attention mechanism is described by a directed graph D whose vertex set is [n] = {1, …, n}. The set of arcs (directed edges) represent the set of inner products that the attention mechanism will consider. Let N(i) denote the out-neighbors set of node i in D, then the i-th output vector of the generalized attention mechanism is defined as ATTN_D(X)_i = x_i + Σ_h σ( Q_h(x_i) K_h(X_{N(i)})ᵀ ) · V_h(X_{N(i)}).
译文
广义注意力由有向图 D 描述，顶点集为 [n]={1,…,n}。弧（有向边）表示注意力会考虑的内积集合。令 N(i) 为节点 i 在 D 中的出邻域，则第 i 个输出为：ATTN_D(X)_i = x_i + Σ_h σ( Q_h(x_i) K_h(X_{N(i)})ᵀ ) · V_h(X_{N(i)})。
generalized attentionout-neighbors N(i)
§24
小结 · 完全图 = 标准 Transformer；稀疏图 = 少算内积。
Original
where Q_h, K_h : Rᵈ → Rᵐ are query and key functions respectively, V_h : Rᵈ → Rᵈ is a value function, σ is a scoring function (e.g. softmax or hardmax) and H denotes the number of heads. Also note X_{N(i)} corresponds to the matrix formed by only stacking {x_j : j ∈ N(i)} and not all the inputs. If D is the complete digraph, we recover the full quadratic attention mechanism of Vaswani et al.
译文
其中 Q_h、K_h 是 query/key 函数，V_h 是 value 函数，σ 是打分函数（如 softmax 或 hardmax），H 为头数。X_{N(i)} 只由邻居 {x_j : j∈N(i)} 堆叠而成，而非全部输入。若 D 是完全有向图，则退回 Vaswani 等的全二次注意力。

§25
小结 · 操作对象变成掩码矩阵 A：1=算注意力，0=不算。
Original
To simplify our exposition, we will operate on the adjacency matrix A of the graph D even though the underlying graph maybe sparse. To elaborate, A ∈ [0,1]^{n×n} with A(i,j)=1 if query i attends to key j and is zero otherwise. For example, when A is the ones matrix (as in BERT), it leads to quadratic complexity, since all tokens attend on every other token. This view of self-attention as a fully connected graph allows us to exploit existing graph theory to help reduce its complexity.
译文
为叙述简便，我们在图 D 的邻接矩阵 A 上讨论（即便图稀疏）。A ∈ [0,1]^{n×n}，A(i,j)=1 表示 query i 关注 key j，否则为 0。例如 BERT 中 A 全为 1，导致二次复杂度，因为所有 token 互相关注。把自注意力看成全连接图，便可借助图论来降低复杂度。
adjacency matrix
§26
小结 · 设计目标二象性：路径要短（信息传得快）+ 要有局部性（语言邻近重要）。
Original
The problem of reducing the quadratic complexity of self-attention can now be seen as a graph sparsification problem. It is well-known that random graphs are expanders and can approximate complete graphs in a number of different contexts including in their spectral properties. We believe sparse random graph for attention mechanism should have two desiderata: small average path length between nodes and a notion of locality, each of which we discuss below.
译文
于是，降低自注意力二次复杂度可视为图稀疏化问题。众所周知，随机图是扩展图，能在包括谱性质在内的多种意义下近似完全图。我们认为，用于注意力的稀疏随机图应具备两点：节点间平均路径短，以及某种局部性——下文分别讨论。
graph sparsificationexpanderaverage path lengthlocality
§27
小结 · 积木① 随机注意力：每行约 r 个随机 1，换「短路径 / 快混合」。
Original
Let us consider the simplest random graph construction, known as Erdős-Rényi model, where each edge is independently chosen with a fixed probability. In such a random graph with just Θ̃(n) edges, the shortest path between any two nodes is logarithmic in the number of nodes. As a consequence, such a random graph approximates the complete graph spectrally and its second eigenvalue (of the adjacency matrix) is quite far from the first eigenvalue. This property leads to a rapid mixing time for random walks in the graph, which informally suggests that information can flow fast between any pair of nodes. Thus, we propose a sparse attention where each query attends over r random number of keys i.e. A(i,·)=1 for r randomly chosen keys (see Fig. 1a).
译文
考虑最简单的随机图：Erdős-Rényi 模型，每条边以固定概率独立出现。在仅有 Θ̃(n) 条边的此类图中，任意两点最短路径对节点数是对数级的。因此它在谱上近似完全图，邻接矩阵第二特征值与第一特征值相距较远，随机游走混合快——非正式地说，信息能在任意节点对之间快速流动。于是我们提出：每个 query 关注 r 个随机 key，即对随机选出的 r 个位置令 A(i,·)=1（见图 1a）。

6 Conclusion 结论 1 段

§64
小结 · 收束：线性稀疏 + 全局保表达力 + NLP/基因组实证；稀疏有代价但值得。
Original
We propose BIGBIRD: a sparse attention mechanism that is linear in the number of tokens. BIGBIRD satisfies a number of theoretical results: it is a universal approximator of sequence to sequence functions and is also Turing complete. Theoretically, we use the power of extra global tokens to preserve the expressive powers of the model. We complement these results by showing that moving to sparse attention mechanism do incur a cost. Empirically, BIGBIRD gives state-of-the-art performance on a number of NLP tasks such as question answering and long document classification. 实现要点：块稀疏（与附录/工程叙述对齐） 3 段

§65
小结 · 工程精髓：稀疏在块与块之间；块内仍 dense GEMM。
Original
In practice, BigBird implements the sparse pattern at block granularity rather than selecting arbitrary individual token neighbors for every query. The sequence is partitioned into blocks; random, window, and global connections are realized as block-level masks so that each allowed block-pair can be computed with dense matrix multiplication kernels.
译文
实践中，BigBird 在块粒度上实现稀疏图案，而不是让每个 query 任意挑选零散 token 邻居。序列被分成块；随机、窗口与全局连接都落实为块级掩码，从而使每个被允许的块对可用密集矩阵乘内核计算。

§66
小结 · 复杂度记账：线性来自「每行度数≈常数」；块化只是让 GPU 真能跑到这个渐近。
Original
This block-sparse realization is crucial for accelerators: scattered token-level gathers destroy memory coalescing and under-utilize Tensor Cores, whereas block masks preserve contiguous computation inside each selected block while still keeping the number of blocks linear in sequence length. With global g, window w and random r treated as constants (or slowly growing), attention cost scales as O(n · (g + w + r)) rather than O(n²).
译文
这种块稀疏实现对加速器至关重要：token 级零散 gather 破坏合并访存、吃不满 Tensor Core；而块掩码在每个选中块内部保持连续计算，同时使块的数量仍对序列长度保持线性。当全局 g、窗口 w、随机 r 视为常数（或缓慢增长）时，注意力代价为 O(n·(g+w+r)) 而非 O(n²)。

名词重点解释 57 条

BIGBIRD

本文提出的稀疏注意力：全局 + 滑动窗口 + 随机边，复杂度对长度线性。

full attention

每个 query 关注所有 key 的标准自注意力，复杂度 O(n²)。

full self-attention

同 full attention：序列内全体两两注意力。

sparse attention

每个 query 只关注 key 的一个子集。

quadratic dependency

计算/内存随序列长度平方增长。

global tokens

与全序列双向（或按定义）连接的枢纽 token，数量 O(1)。

window attention

每个位置只关注左右各 w/2 邻域。

random attention

每个位置额外关注 r 个随机位置（常按块）。

adjacency matrix

A(i,j)=1 表示 i 对 j 做注意力。

graph sparsification

减少图中边数同时尽量保留完全图的重要性质。

Erdős-Rényi

每条边独立以固定概率出现的随机图模型。

small world graphs

高局部聚类 + 短平均路径的图；Watts–Strogatz 是代表。

clustering coefficient

衡量局部抱团程度的图统计量。

Watts-Strogatz

先做环上窗口邻接，再随机重连一部分边的小世界模型。

sliding window

沿序列滑动的固定宽度邻域连接。

ITC

Internal Transformer Construction：把已有 token 标成全局。

ETC

Extended Transformer Construction：额外插入全局 token。

star-graph

一个中心连接所有其他节点的图，理论证明的关键结构。

universal approximator

能以任意精度逼近某类函数（此处为连续 seq2seq）。

Turing complete

在假设下可模拟任意图灵机计算。

block sparse

以块为单位的稀疏掩码；块内仍做密集运算。

block mask

决定哪些 block-pair 参与计算的块级掩码。

block sparsity

利用块结构降低复杂度/提高核效率的稀疏方式。

Longformer

窗口+全局的近亲工作；BigBird 额外加随机并强化理论。

Sparse Transformer

Child et al. 的固定稀疏图案注意力。

out-neighbors N(i)

图中节点 i 的出邻居集合，即 query i 允许看见的 key 集合。

generalized attention

由有向图 D 规定允许内积集合的注意力形式。

complete digraph

任意有序点对都有弧的有向完全图＝全注意力。

expander

稀疏却具有类似完全图扩展/谱性质的图。

average path length

图中节点对最短路径长度的平均，越小信息传得越快。

locality

连接或依赖主要集中在邻近位置的现象。

locality of reference

访问/依赖集中在邻近地址或邻近 token。

mixing time

随机游走收敛到平稳分布所需时间；短则信息混合快。

contextual mapping

把整句上下文编码进每个位置表示的唯一映射，用于万能近似证明。

O(n) inner products

注意力内积次数随序列长度线性增长。

permutation equivariant

expressivity

self-attention

SIMD

pretraining
