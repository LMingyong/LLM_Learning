Gated DeltaNet

本夹对应 arXiv:2412.06464：把 Mamba2 的标量门 α 与 DeltaNet 的 delta rule 合成 gated delta rule。精读含独立公式卡；上游读 理论原点 / 并行训练，下游读 KDA。

核心：α(I−βkkᵀ) 对照：Mamba2 · DeltaNet 训练：WY 分块 + 门控 下游：→ KDA

英文贴近 ICLR 2025 论文。建议：先扫 公式墙 看三式对照，再读 §3.1；然后进 KDA 看通道门。

公式墙（速查） 谱系一览

以下公式从正文抽出，便于对照；段内还有更细的展开卡。

Mamba2 · 标量衰减
\[S_t=\alpha_t S_{t-1}+v_t k_t^\top\]
全体关联同一比例遗忘；擦除不够定点。
DeltaNet · 定点擦写
\[S_t=S_{t-1}(I-\beta_t k_t k_t^\top)+\beta_t v_t k_t^\top\]
按 key 纠错；难快速清空整块记忆。
式 (10) · Gated Delta Rule
\[S_t=S_{t-1}\bigl(\alpha_t(I-\beta_t k_t k_t^\top)\bigr)+\beta_t v_t k_t^\top\]
α→0 快速清空；α→1 退化为纯 DeltaNet。
读出
\[o_t=S_t q_t\]
状态大小固定，与序列长度无关。

Abstract 摘要 3 段

§1
小结 · 两条线：门控管「忘多少」，delta 管「改哪条」。
Original
Linear Transformers are efficient alternatives to standard Transformers, but retrieval and long-context performance remain limited. Recent work explored two mechanisms: gating for adaptive memory control, and the delta update rule for precise memory modifications.
译文
线性 Transformer 是标准注意力的高效替代，但检索与长上下文仍受限。近期工作探索两类机制：门控做自适应记忆控制，以及 delta 更新做精确记忆修改。
gatingdelta rulelinear attention
§2
小结 · 本文公式核心：把 α 和 β 装进同一个递推。
Original
These mechanisms are complementary: gating enables rapid memory erasure while the delta rule facilitates targeted updates. We introduce the gated delta rule and a parallel training algorithm optimized for modern hardware.
译文
二者互补：门控擅长快速擦除，delta 擅长定点更新。我们提出 gated delta rule，并给出面向现代硬件的并行训练算法。
gated delta rule
§3
小结 · 结论：单模打赢两前驱；混合还能再抬一手。
Original
Gated DeltaNet surpasses Mamba2 and DeltaNet on language modeling, common-sense reasoning, in-context retrieval, length extrapolation, and long-context understanding. Hybrids with sliding-window attention or Mamba2 further improve efficiency and quality.
译文
Gated DeltaNet 在语言建模、常识推理、上下文检索、长度外推与长上下文理解上超过 Mamba2 与 DeltaNet；与滑窗注意力或 Mamba2 的混合进一步提升效率与质量。

1 Introduction 引言（关键） 3 段

§4
小结 · 有限状态容量是一切门控/纠错动机的源头。
Original
Linear Transformers store outer-product key–value associations in a fixed-size state. When sequence length exceeds dimensionality, memory collisions hinder exact retrieval.
译文
线性 Transformer 用固定大小状态存外积 KV 关联；序列长度超过维度后，「记忆碰撞」阻碍精确检索。
associative memorymemory collision
§5
小结 · 一张表：α=全局刮板，β=局部橡皮擦。
Original
Mamba2 uses a scalar gate α_t that uniformly decays all associations—fast to clear, but not targeted. DeltaNet softly replaces one key’s binding via β_t—precise, but slow to flush irrelevant context.
译文
Mamba2 用标量门 α_t 均匀衰减全部关联——清空快，但不定点。DeltaNet 用 β_t 软替换某一 key 的绑定——精确，但难快速冲掉无关上下文。

§6
小结 · 工程承诺：表达力升级，并行训练日程可复用。
Original
Gated delta rule unifies both: α_t→0 clears memory promptly; α_t→1 recovers pure delta updates. Training extends DeltaNet’s WY/chunkwise algorithm with gating terms.
译文
Gated delta rule 统一二者：α_t→0 迅速清空；α_t→1 退回纯 delta。训练在 DeltaNet 的 WY/分块算法上并入门控项。

2 预备：Mamba2 与 DeltaNet 2 段

§7
小结 · Mamba2 = 加性写入 + 全局遗忘。
线性注意力
\[S_t=S_{t-1}+v_t k_t^\top,\quad o_t=S_t q_t\]
Mamba2
\[S_t=\alpha_t S_{t-1}+v_t k_t^\top,\quad \alpha_t\in(0,1)\]
全体一起忘，无法只擦某一条绑定。
Original
Vanilla linear attention accumulates S_t = S_{t−1} + v_t k_tᵀ. Mamba2 adds scalar decay α_t so every association shrinks by the same factor each step.
译文
朴素线性注意力累加 S_t=S_{t−1}+v_t k_tᵀ。Mamba2 加标量衰减 α_t，每一步所有关联按同一比例缩小。
Mamba2α
§8
小结 · DeltaNet = 定点纠错，缺快速整页清空。
DeltaNet
\[S_t=S_{t-1}(I-\beta_t k_t k_t^\top)+\beta_t v_t k_t^\top\]
Original
DeltaNet retrieves the old value for the current key, mixes with the new value by writing strength β, then remove-and-write—equivalent to a generalized Householder transition.
译文
DeltaNet 取回当前 key 的旧 value，按写入强度 β 与新 value 混合，再擦写——等价于广义 Householder 转移。
DeltaNetβHouseholder

3.1 Gated Delta Rule（核心公式） 3 段

§9
小结 · 必背：S ← α(I−βkkᵀ)S + βvkᵀ。
式 (10)
\[S_t=S_{t-1}\bigl(\alpha_t(I-\beta_t k_t k_t^\top)\bigr)+\beta_t v_t k_t^\top\]
α 管全局寿命，β 管本次纠错强度。
极限行为
\[\alpha_t\to 0\;\Rightarrow\;\text{快速清空};\quad \alpha_t\to 1\;\Rightarrow\;\text{纯 DeltaNet}\]
Original
Equation (10): apply scalar gate α_t before / around the Householder delta transition, then write β_t v_t k_tᵀ. This is the gated delta rule.
译文
式 (10)：在 Householder 型 delta 转移上乘标量门 α_t，再写入 β_t v_t k_tᵀ。这就是 gated delta rule。
教学示意 · 对应论文式 (10)

§10
小结 · 理论口令：遗忘松弛 + 重构纠错，一张目标函数写清。
Original
Through an online-learning view (Table 1), Gated DeltaNet relaxes the retention regularizer with α_t while keeping a delta-style regression term on the (gated) prediction error—combining selective forgetting with associative-recall objectives.
译文
从在线学习视角（表 1）：Gated DeltaNet 用 α_t 放松「贴近旧状态」正则，同时保留对（门控后）预测误差的 delta 风格回归项——兼具选择性遗忘与联想回忆目标。
online learningassociative recall
§11
小结 · 算法：不是另起炉灶，是在 DeltaNet 并行日程上加门。
Original
Training extends the WY / UT chunkwise algorithm of scalable DeltaNet by folding α into the Householder products, preserving matmul-heavy kernels for Tensor Cores.
译文
训练把 α 折进 Householder 乘积，扩展可扩展 DeltaNet 的 WY/UT 分块算法，保持吃 Tensor Core 的 matmul 核。

Reading map in this repo: papers/deltanet (2021 theory) → papers/deltanet-parallel (2024 scalable training) → this page (scalar α + δ) → papers/kda (channel-wise Diag(α) + MLA hybrid).

§17
小结 · 公式差一个符号量级，论文就该分开放。
对照三式
\[\begin{aligned}\mathrm{DeltaNet}&:\;S\leftarrow S(I-\beta kk^\top)+\beta vk^\top\\ \mathrm{GDN}&:\;S\leftarrow S(\alpha(I-\beta kk^\top))+\beta vk^\top\\ \mathrm{KDA}&:\;S\leftarrow (I-\beta kk^\top)\mathrm{Diag}(\alpha)S+\beta vk^\top\end{aligned}\]
Original
Do not confuse folders: DeltaNet has β only; Gated DeltaNet adds scalar α; KDA replaces α with Diag(α_t) per channel.
译文
分夹勿混：DeltaNet 只有 β；Gated DeltaNet 加标量 α；KDA 把 α 换成逐通道 Diag(α_t)。
Diag(α_t)αβ

名词重点解释 27 条

Gated DeltaNet

结合标量遗忘门 α 与 delta rule β 的线性注意力架构（本文）。

gated delta rule

S←S(α(I−βkkᵀ))+βvkᵀ：全局遗忘 + 定点纠错。

DeltaNet

仅用 delta rule 的线性注意力；理论见 papers/deltanet，可扩展训练见 papers/deltanet-parallel。

Mamba2

带标量衰减的加性状态更新：S←αS+vkᵀ。

α

数据相关标量遗忘/衰减因子。

β

delta 写入强度 / 学习率。

delta rule

按 key 读出旧值、按误差纠错写入的更新。

gating

数据相关的记忆清除/保留控制。

linear attention

固定大小状态的线性复杂度注意力族。

associative memory

把 key 映射到 value 的可写可读状态 S。

memory collision

序列过长导致有限维度状态无法区分过多 KV 绑定。

Householder

I−βkkᵀ 型秩一修正转移。

WY representation

紧凑表示一串 Householder 乘积，支撑分块并行。

UT transform

把 WY 因子写成可 matmul 的块三角形式。

chunkwise

块间递推、块内并行的训练日程。

online learning

把递推看成逐步最小化在线目标的闭式更新。

associative recall

上下文中按 key 找回 value 的能力。

S-NIAH

长上下文检索探针套件（needle-in-a-haystack 变体）。

hybrid

GDN 与滑窗注意力或 Mamba2 等混合堆叠。

sliding window

局部滑窗 softmax 注意力。

ShortConv

QKV 后的轻量短卷积。

SiLU

常用激活；配合 L2Norm 稳定 q/k。

L2Norm

对 q/k 的 L2 归一化。

output gate

输出侧数据相关门。

KDA

Kimi Delta Attention：把 α 升级为 Diag(α)（papers/kda）。

Diag(α_t)

通道级对角遗忘；相对 GDN 的标量 α。

Eq.10

本文 gated delta rule 主公式。
